## Create your server

From the **Create a server** page pick Palworld. The game is RAM-hungry — 16GB is the comfortable experience, and we do not recommend going below 8GB.

After payment your machine starts provisioning — follow its progress on the order page. There is nothing to set up: as soon as the machine is ready your server downloads the latest Palworld build from Steam and starts on its own.

> [!note] The first install takes a while — the game is a large download. Watch all of it from the console tab.

## Join the game

:::when server.address
Copy your address:

@[field](server.address)

Then inside Palworld:

1. From the main menu choose **Join Multiplayer Game**
2. At the bottom, enable joining via a direct IP address
3. Paste the address and port, and join
:::else
Your server is still setting up, so it has no address yet — it appears here the moment the install finishes.

@[open](console)
:::

> [!note] If you set a join password in the settings, the game will ask every player for it. This is the easiest way to keep the server private for your group.

## Your first night

- Player progress is stored on the server — everyone continues where they left off, even after leaving
- The server keeps running with nobody online: your bases and ranch Pals work while you sleep
- The default death penalty drops your items — you can soften it from the settings tab
- Your world is safe — we take automatic backups, and you can take one yourself

@[open](backups)

> [!warning] Palworld patches often. Your server pulls the newest Steam build every time it starts, so a restart is all it takes to catch up after a game update.
